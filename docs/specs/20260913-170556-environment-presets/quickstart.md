# Quickstart: Validate Environment Presets

1. Automated evidence (2026-09-13): `cargo fmt --all -- --check` and `cargo test --workspace` pass (150 tests). Run `cargo clippy --workspace --all-targets --all-features -- -D warnings` and `cargo build --workspace` before merging.
2. Start a match with each preset. Verify setup label/summary, retained selection across a new round, and terrain/sky identity.
3. Compare identical shots: Moon longer, Crusher shorter, Storm windier than Earth.
4. Run 20 Turnwind turns: wind changes once before aiming and remains stable through every shot.
5. Verify Bowl starts and central depression at every player count; inspect Moon stars/no clouds, Storm clouds, and Crusher warm palette.

Manual visual/playability evidence is still required for every preset; record the reviewer, platform, and result here after completing steps 2–5.
