# Impact Screen Flash Contract

| Observation | Presentation outcome |
|---|---|
| New resolved terrain impact | Start one white pulse from impact scale |
| Same persistent impact | Do not restart pulse |
| Multi-tank damage/elimination | No additional pulse |
| Out-of-bounds flight | No pulse |

The pulse is short, bounded, and presentation-only. Failure to show it leaves all existing impact presentation and authoritative outcomes intact.
