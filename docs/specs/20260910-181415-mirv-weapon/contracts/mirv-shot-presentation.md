# MIRV Shot and Presentation Contract

| Authoritative condition | Required outcome |
|---|---|
| Successful MIRV fire | Consume one round; create one carrier owned by the committed shot. |
| Surviving carrier reaches apex | Replace once with five indexed children at resolved state plus fixed impulses. |
| Pre-split carrier terrain/bounds outcome | Normal unsplit resolution; no children. |
| Child terrain impact | Normal explosion/damage/crater/support work; ordered presentation event; remove only that child. |
| Child bounds outcome | Remove only that child; no impact event. |
| Any active record | Continue resolving fire. |
| Empty record set and no settling | Complete existing firing turn once. |

| Observer input | Required behavior | Must not |
|---|---|---|
| Carrier | Human carrier follow; AI tactical wide | Affect simulation. |
| Child snapshot | Wider bounded spread/aggregate framing | Chase arbitrary children. |
| Ordered impact events | Visual per impact; coalesced pulse; bounded audio | Re-resolve gameplay or gate handoff. |
| Empty shot with impacts | One aggregate impact view | Snap between child impacts. |

Human `4` selects MIRV when available; fire has no split/count control. AI continues Basic-Shell decisions through the shared fire path.
